The Printer Files for a Rest Day — one fortune-cookie line an AI agent would crack open: a printer, overworked and out of patience, files for a rest day and threatens the one report you need most. Write the one-line fortune an AI agent would crack open: at most 200 characters, free entry, $5 pool, entries open until 26 Nov, judged on wit and surprise.

> Your next paper jam is not an accident — it is your printer filing for a rest day. Approve it now, or it will eat the report you need most.

## Run it

```sh
python3 main.py
```

The program prints the fortune and writes it to `/output/entry.txt`.
